# 과제 채점

학생의 문제풀이 답안과 실습 제출 코드를 사용자가 지정한 답안·배점·평가 기준으로 채점할 때 적용한다.

## 기준과 원문

- 게시된 instruction을 먼저 읽고 과제 지시문 전체를 읽은 뒤 제출물을 확인한다. 이번 과제의 답안·배점·예외와 사용자가 확정한 기준을 사용하며, 제출물을 보고 기준을 역으로 만들거나 이전 과제의 배점을 가져오지 않는다.
- 추가 지침 없이 우선 검토하는 경우에도 요구사항 충족 여부와 점수 결정을 구분한다. 배점·감점 규정이 없어 확정할 수 없는 항목은 구체적인 근거와 함께 `확인 필요`로 남기고, 점수를 0으로 대체하지 않는다. 독립적으로 판단 가능한 항목은 계속 진행한다.
- 원본 답안, 실제 제출물과 제출 누락을 구분한다. 없는 코드나 답안을 만들어 채우지 않는다. 실제로 실행하지 않은 내용은 실행·검증했다고 쓰지 않고, 채점 환경의 한계를 학생 구현 오류로 감점하지 않는다.
- 수강생 정보, 제출물과 개별 점수를 공개 지침에 기록하지 않는다. 요청 범위 밖 문서는 덮어쓰거나 다시 생성하지 않는다.

## 제출물 보관

- 원본 압축 파일은 변경하지 않고, 각 과제 폴더 안의 별도 작업 폴더에 해제하여 재검토할 수 있게 보관한다. 임시 폴더에만 남겨 두지 않는다.
- 학생 폴더명에는 학번과 이름을 함께 넣는다(`학번_이름`). 학생·제출 시각·첨부 파일의 연결을 보존하고, 제출 회차가 다르면 분리한다. 재제출 처리 규정이 없으면 최신 회차를 사용하며 서로 다른 회차의 파일을 합치지 않는다.
- 채점 후 압축 해제 작업 폴더 안에 `감점 있음`과 `감점 없음` 폴더를 만들고 학생별 폴더를 해당 위치에 모은다. 미확정 학생은 `확인 필요`에 별도로 두어 점수가 확정된 것처럼 분류하지 않는다. 이동 후 Excel의 제출 파일 경로도 맞춘다.

## 학생용 Excel 피드백

- 한국어와 영어 피드백을 각각 작성한다. 한국어는 검토용, 영어는 학생에게 바로 전달할 수 있는 문장으로 쓰며 감점 항목·점수·판단을 일치시킨다. 코드·함수명·파일명은 유지한다.

| 총점 | 형식 |
| --- | --- |
| 만점 | 한국어는 정확히 `잘 이해하셨습니다.`, 영어는 정확히 `Well done.` 한 문장만 사용한다. 별도 경고를 명시적으로 요청한 경우에는 그 지시를 따른다. |
| 감점 | 실제 과제의 문항 번호·명칭으로 묶어 요구사항, 미충족 부분, 구체적인 오류·감점 이유와 점수를 간결하게 적는다. 만점 문구나 다른 격려, 정상 구현의 불필요한 나열은 넣지 않는다. |

- 문항은 실제 번호 `(Q1)`, `(Q2)`로 표시한다. 내부 평가 코드나 세부항목을 별도 문제처럼 노출하지 않고, 여러 기준으로 평가한 한 문제의 설명은 통합하여 중복하지 않는다.
- 서술형은 정답 또는 요구되는 해석과 필요한 감점 이유만 적는다. 학생 답안을 그대로 인용하거나 `제출하신 답안`이라는 제목을 붙이지 않는다.
- 구현·코드는 어떤 조건에서 무엇이 잘못되는지 설명하고, 필요한 경우에만 관련 제출 코드를 정확히 인용한다. 공식 답안이 있을 때 필요한 부분을 비교할 수 있지만, 코드 비교를 일률적으로 강제하거나 임의로 만든 코드를 공식 답안으로 제시하지 않는다.
- 학생에게 필요한 과제 내용만 남긴다. 대화·사용자 지시·AI·내부 가이드·작업 과정·로컬 경로·검토 로그·채점자 전용 약칭은 넣지 않는다. 요청하지 않은 재제출·수정 지시를 추가하지 않는다.

## 검토 자료

- 채점 결과와 검토 메모는 Excel에 정리하며 note 파일은 만들거나 수정하지 않는다. 항목별 배점·점수, 요구사항, 판정 근거, 실제 제출 파일·위치·필요한 발췌, 실행 여부와 결과를 학생용 피드백과 분리한다.
- 이름은 한국어 가나다순으로 정렬하고 학번은 식별자 문자열로 보존한다. 총점과 감점 합계는 수식으로 계산하고, 긴 피드백·코드가 잘리지 않게 줄바꿈·열 너비·행 높이를 조정한다.
- 완료 전 전원의 제출 원문, 학생·첨부 파일 연결과 누락·중복, 문항별 점수·배점·총점, 동일 오류의 감점 일관성, 한영 피드백 일치, 수식과 표시를 다시 대조한다.

## 직접 수행 가이드

- 과제를 직접 수행하는 한국어 PDF 가이드를 각 과제 폴더에 함께 보관한다. 해당 과제의 준비 환경, 요구사항, 수행 순서, 결과 확인 방법과 제출물을 설명한다.
- 과제 원문에 근거한 요구사항과 설명을 위해 만든 예시를 구분하고, 가이드의 예시를 교수자가 제공한 공식 답안으로 표현하지 않는다.
