# 과제 채점

학생의 문제풀이 답안과 실습 제출 코드를 사용자가 지정한 답안·배점·평가 기준으로 채점할 때 적용한다.

## 기준과 원문

- 이번 과제의 답안·배점·예외와 사용자가 확정한 기준을 사용한다. 이전 학기 자료는 작성 방식만 참고한다.
- 원본 답안, 실제 제출물과 제출 누락을 구분한다. 없는 코드나 답안을 만들어 채우지 않는다.
- 수강생 정보, 제출물과 개별 점수를 공개 지침에 기록하지 않는다. 사용자 수정 note와 요청 범위 밖 문서는 덮어쓰거나 다시 생성하지 않는다.

## 학생용 Excel 피드백

| 총점 | 형식 |
| --- | --- |
| 만점 | 정확히 `잘 이해하셨습니다.` 한 문장. 영역별 점수·추가 피드백·이모티콘 제외 |
| 감점 | 모든 영역을 `[영역명][획득점수/영역만점]`으로 표시. 만점 영역은 점수만, 감점 문항은 오답·제출 누락 사유만 작성. 격려 문구 제외 |

- 요청하지 않은 재제출·수정 지시를 넣지 않는다. 사용자가 명시적으로 요구한 감점·인정 사유는 간결하게 남긴다.
- 문항은 실제 번호 `(Q1)`, `(Q2)`로 표시한다. 내부 채점 세부항목 번호를 노출하지 않고, 여러 기준으로 평가한 한 문제의 정답은 한 번만 통합해 적는다.
- `문제풀이`: `(Qn) 답안:` 뒤 정답을 짧은 문장으로 적는다. 학생 답안 인용과 `제출하신 답안` 제목을 넣지 않는다.
- `실습제출` 코드 오답: `(Qn) 답안:` 아래 원본 답안 코드를 그대로, `(Qn) 제출하신 코드:` 아래 실제 제출 코드를 그대로 넣는다. 자연어 설명으로 코드 비교를 대신하지 않는다.
- 필요한 파일·코드가 없으면 확인할 수 없어 감점했다는 사유를 적는다.

## 검토 자료

- 검토용 Excel에는 항목별 배점, 답안 요구, 실제 제출과의 차이, 감점 점수와 원문 근거를 기록한다. 학생에게 전달하는 피드백과 열을 구분한다.
- 채점 note는 `문제풀이1`, `문제풀이2`, `실습제출 Q1, Q2 오답`처럼 영역과 감점 항목·핵심 사유만 표시한다. 중복 총점, 일반 배점 설명과 진행·검토 기록을 넣지 않는다.
- 완료 전 제출 원문, 문항별 점수, 총점과 피드백을 대조해 누락, 잘못 부여한 점수, 인용·합계 오류를 확인한다.
